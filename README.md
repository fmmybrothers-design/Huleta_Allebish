## ✨ Overview
A cutting-edge, professional portfolio website featuring advanced animations, interactive elements, and modern design patterns.

## 🎯 Features

### **Core Pages**
- **Home** - Dynamic hero section with typing effect and statistics
- **About** - Background, education, and work experience
- **Main** - Technical skills and expertise showcase
- **Projects** - Featured projects with detailed descriptions

## 🔧 Customization

### Change Your Information
Edit the HTML files to update:
- Name and title
- Work experience
- Projects
- Skills
- Contact information

### Modify Colors
Update CSS custom properties in `styles.css`:
```css
:root {
    --accent-blue: #yourcolor;
    --accent-purple: #yourcolor;
}
```

### Adjust Animations
In `advanced.js`, modify:
- Typing speed
- Particle count
- Animation durations
- Cursor behavior
